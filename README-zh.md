# 时间戳记录

[English](README.md)

用于工作中临时记录的小工具。表格共 **8 行、2 列**，每条记录由自动生成的时间戳和可编辑的文本组成。记录保存在本地 JSON 数据库文件中，下次连接该文件即可继续使用。

## 开始使用

1. 使用桌面版 Microsoft Edge 或 Google Chrome 打开 `index.html`。无需安装软件、启动本地服务或联网。
2. 点击 **Connect database（连接数据库）**，选择项目中的 `records.json`，允许浏览器读取和修改。如果要使用独立的新数据库，点击 **New（新建）**，选择新的文件名或保存位置。
3. 点击 **Add（新增）** 生成时间戳，然后在右侧输入文本。
4. 等待状态显示 **Saved locally（已保存到本机）** 后再关闭页面。

首次新建时，请在保存窗口中手动选择 `index.html` 所在文件夹；之后新建会优先使用上次数据库所在文件夹。若浏览器未记住数据库，保存位置由浏览器决定。

每次打开页面时默认显示**英文**。点击 **中文** 切换为中文，点击 **English** 切回英文。切换语言会保留当前文本，不会修改数据库内容。

## 记录操作

可以把这个表格理解为一个最多容纳 8 条记录的非典型栈：新记录追加在已有记录下方，也可以直接编辑或删除中间条目。删除后，下方记录自动上移；填满后再新增，会移除最上方、最早加入的一条。

时间戳为只读内容，通过“新增”生成，随整行删除。仅清空文本不会清除时间戳，该行仍计为已使用。同行有时间戳时，文本格才可编辑和复制。

| 操作 | 效果 |
| --- | --- |
| 新增 | 在已有记录下方新增一条，填入当前时间戳。 |
| 编辑文本 | 修改或清空文本，支持换行。 |
| 复制 | 将对应单元格的内容复制到剪贴板。 |
| 删除一行 | 删除整条记录，下方记录自动上移。 |

## 自动保存与历史记录

- 每次文本输入、新增或删除都会立即加入文件保存队列，按顺序写入。只有写入完成后才显示“已保存到本机”，无需另点保存按钮。
- 记录内容存放在选定的数据库文件中。浏览器只尝试记住文件句柄和访问授权，不另外缓存一份记录内容。
- 再次打开时，页面会尝试自动连接并读取文件。浏览器要求再次授权时，点击“连接数据库”并允许读写。如果浏览器提供持久授权选项，可用于减少后续提示。
- 清理浏览器数据或移动 HTML 文件后，可能需要重新选择数据库。只要原数据库文件完好，仍可读取其中的历史记录。
- 备份或换电脑时，先等待“已保存到本机”，再复制数据库文件。在目标电脑上打开 HTML，连接这份数据库即可。

建议同一个数据库只在一个页面中编辑。如果其他页面或程序修改了文件，应用会停止写入，避免覆盖外部修改。请先复制尚未保存的文本，再刷新并重新连接。遇到权限或磁盘错误时，保留页面，处理问题后点击“重试”或“重新授权并重试”。

本版本最多接受 8 条记录。如果数据库超过 8 条，应用会提示并保留原文件，不会自动截断；请先备份，再用旧版将记录减少到 8 条后连接。
